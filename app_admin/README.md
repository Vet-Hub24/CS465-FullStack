# Travlr Getaways Admin

This Angular admin single-page application is configured for Angular 17 to match the CS 465 Module Six guide.

## Run

Install dependencies:

```bash
npm install
```

Start the admin SPA:

```bash
npm start
```

The Angular admin SPA runs at `http://localhost:4200` and calls the Express API at `http://localhost:3000/api`.
